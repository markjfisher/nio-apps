# nio-apps MS-DOS Diagnostics

This directory contains MS-DOS-only diagnostic support for `nio-apps`.

The user-facing MS-DOS `F*` utilities live in `../../nio-core-apps`.

The MS-DOS `config-nio` application lives in `../../nio-config`.

`scripts/create_msdos_img.py` remains here for building diagnostic/test images
from this repository's own outputs.
